Ticino Server

TicinoServer.exe e' l'app per Windows della mappa Ticino di MagliasinaNG. Non serve installarla: avviala da dove vuoi.

- Download e aggiornamenti: scarica la mappa dalla release di GitHub nella cartella che scegli (circa 52 GB), solo cio'
  che e' cambiato, con ripresa dei download interrotti e controllo sha256. Gli aggiornamenti si installano quando
  server e gioco sono chiusi.
- Grafica: distanza visiva di alberi, terreno lontano, edifici, strade e dettagli (settings\ticino.json di BeamNG).
- Server: avvia e ferma ticino_server.exe (scaricato dall'app stessa), mostra il suo registro e lo stato.
- Gioca: avvia il server e BeamNG direttamente nella mappa.

Le impostazioni dell'app sono in %LOCALAPPDATA%\TicinoServer (settings.json, app.log, server\).
Una release in bozza (draft) si scarica solo con GitHub CLI connesso (gh auth login).
